# Student Grade Calculator 🐍

A beginner-friendly Python project that calculates a student's average marks and assigns a grade.

## Features

* Accepts a student's name and marks in three subjects
* Calculates the average marks
* Assigns a grade based on the average
* Validates marks between 0 and 100
* Handles non-numeric input using `try-except`
* Displays a formatted student report

## Technologies Used

* Python 3
* VS Code
* GitHub

## How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run:

   `python grade_calculator.py`

## Grading Criteria

* A: 90 and above
* B: 75–89.99
* C: 60–74.99
* D: 40–59.99
* F: Below 40
